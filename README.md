# Basic Python Programs

A collection of small standalone Python programs for practice.

## Programs

| File | Description |
|---|---|
| programs/calculator.py | Simple command line calculator |
| programs/factorial.py | Factorial of a number |
| programs/fibonacci.py | Fibonacci series generator |
| programs/prime_check.py | Check if a number is prime |
| programs/palindrome.py | Check if a string is a palindrome |
| programs/reverse_string.py | Reverse a string |
| programs/temperature_converter.py | Convert Celsius to Fahrenheit and back |
| programs/simple_interest.py | Calculate simple interest |
| programs/bmi_calculator.py | Calculate BMI |
| programs/number_guessing_game.py | Number guessing game |

## Usage

```
python3 programs/<file_name>.py
```

## Requirements

Python 3.6 or above. No external libraries needed.
